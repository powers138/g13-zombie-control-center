# Security Policy

## Supported versions

Security fixes are currently provided for the latest released version of
G13 Zombie Control Center.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Older versions | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability reporting feature for this repository
instead.

When reporting a vulnerability, include:

- The affected version of G13 Zombie Control Center
- The Linux distribution and desktop/session environment
- Steps required to reproduce the issue
- The expected and actual behavior
- Any relevant logs or diagnostic information
- The potential security impact, if known

Normal bugs, compatibility problems, and feature requests should be reported
through GitHub Issues.
